# Funding links to activate after GitHub Sponsors approval

The `jepsenphil` Sponsors URL currently redirects to the normal GitHub profile. Do not copy the staged file into `.github/FUNDING.yml` or add a public badge until the Sponsors page accepts sponsorships.

When the page is live:

1. Copy [FUNDING.yml](FUNDING.yml) to `.github/FUNDING.yml` on the default branch. This enables GitHub's Sponsor button.
2. Add this badge near the CI badges in the root README:

~~~md
[![Sponsor Gridstator](https://img.shields.io/badge/Sponsor-Gridstator-ea4aaa?logo=githubsponsors)](https://github.com/sponsors/jepsenphil)
~~~

3. Open the badge and Sponsor button in a signed-out browser session and confirm both land on the active profile. Then add the same funding link to the VS Code listing if desired.

GitHub's [funding button documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository) defines the `FUNDING.yml` format.
