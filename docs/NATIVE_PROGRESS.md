# Native release progress

The native CLI, controller, worker and extension use automated Rust, TypeScript, VS Code and security checks in CI. The [release acceptance record](../native/contracts/release-acceptance.json) is authoritative for the two Linux stable gates and three separate future Mac stable gates. An `implemented` gate records partial evidence; only `verified` records a release pass.

The repository contains [platform evidence](../native/contracts/evidence/) from Linux x64 and ARM64, macOS Apple Silicon and Intel under Rosetta, and WSL2 validation. Each release is qualified by its own final candidate and source revision. The [validation host guide](../native/VALIDATION_HOSTS.md) lists the remaining host scenarios and collection steps. The [release guide](RELEASING.md) defines final review and publication.

The two Linux stable gates are verified against the [current 2.0.1 final candidate](../native/contracts/evidence/linux-stable-2.0.1/README.md): clean offline runtime and user/root systemd lifecycle on actual x64 and ARM64 hosts, including explicit service replacement. [2.0.0 evidence](../native/contracts/evidence/linux-stable-2.0.0/README.md) remains available for that release. Apple Silicon is an [unsigned development preview](https://github.com/jepsenphil/gridstator/releases/tag/v2.0.1-macos-preview.1); its Docker Desktop and launchd checks continue separately. Intel Mac and signed/notarized macOS distribution are deferred. The desktop companion has a [separate progress record](DESKTOP_COMPANION_PROGRESS.md).
