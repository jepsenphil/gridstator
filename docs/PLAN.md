# Project status and roadmap

Gridstator 2.0.0 was the first public native Linux release; [2.0.1](https://github.com/jepsenphil/gridstator/releases/tag/v2.0.1) is the current stable patch. The [release plan](NATIVE_RELEASE_PLAN.md), [progress](NATIVE_PROGRESS.md) and [acceptance record](../native/contracts/release-acceptance.json) define the remaining work.

| Track | Current state | Next public milestone |
| --- | --- | --- |
| Native CLI/controller/worker | Verified Linux x64/ARM64 release; separate unsigned Apple Silicon preview | Continue platform qualification for future macOS stable support |
| VS Code extension | Native VSIX attached to the Linux GitHub release; Marketplace listing pending | Register and publish `gridstator.gridstator` with trusted publishing |
| Desktop companion | Separate unsigned preview | OS installer and lifecycle qualification after the core release |

See [release readiness](RELEASING.md), the [desktop plan](DESKTOP_COMPANION_PLAN.md) and [desktop progress](DESKTOP_COMPANION_PROGRESS.md).
