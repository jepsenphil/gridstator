# Historical validation evidence

This directory preserves dated test records, tool output, source inventories and platform observations. Some records were captured while the unpublished Node prototype was still in the tree. Their paths and output are kept verbatim so checksums and provenance remain meaningful; they do not describe a supported product or an active release process.

The current [release acceptance record](../release-acceptance.json) identifies the native gates and links to relevant evidence. A historical preview or earlier source revision does not verify the final release bytes. Follow [native release preparation](../../RELEASING.md) and the [validation host guide](../../VALIDATION_HOSTS.md) to collect final evidence.
