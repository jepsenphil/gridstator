# Linux 2.0.0 stable candidate proof

The [candidate run](https://github.com/jepsenphil/gridstator/actions/runs/43280058271) built the final Linux x64 and ARM64 executables from source `1b0dfd96785ccee1bfeafd9222bfd623bdbc301f` on matching GitHub-hosted Ubuntu 24.04 machines. Its six jobs passed: identity, native VSIX package, both native builds, packaged VSIX integration, and assembly. The exact artifact is `native-release-candidate` from run attempt 1.

For each target, `build-info.json` records the version, source, build ID, architecture and executable SHA-256. `clean-runtime.json` is the output of that same executable inside an `alpine:3.21` container run with `--network none`. `linkage.txt` is `readelf -l -d` output with no interpreter or needed shared library. `systemd-proof.json` records the actual host, systemd, Docker and final executable hash. The user and system logs show the isolated [systemd lifecycle test](../../../tests/systemd_e2e.rs) passed with the final executable. That test installs a uniquely named service, rejects implicit replacement, explicitly replaces it, runs a Docker job, checks history, restarts, stops and uninstalls it.

The [candidate workflow](../../../../.github/workflows/native-candidate.yml) shows the exact build and validation commands: `cargo fmt --check`, strict `cargo clippy`, serial `cargo test --locked --all-targets`, `cargo build --locked --release`, `readelf`, offline Alpine execution, and the ignored systemd test run as both the user and root. It also runs `xvfb-run -a node test/run-integration.mjs` with the packaged VSIX and final Linux x64 binary. The workflow output is the full command/result log.

The copied [manifest](gridstator-release.json) and [checksum document](release-SHA256SUMS.txt) identify the downloaded release artifact. The archive executables match both per-target `build-info.json` hashes. A separate isolated x64 installation used `install-native.sh --tag v2.0.0 --bundle-dir <candidate-release> --manifest-sha256 <manifest-digest> --archive-sha256 <archive-digest> --prefix <temporary-prefix>` and produced the same binary hash. The checksums document references downloadable archives, which are deliberately not duplicated in this evidence directory.

This proof qualifies the two Linux stable gates. It does not qualify signed macOS, Docker Desktop capacity, launchd lifecycle, or Intel Mac support. Managed update and schema rollback remain covered by separate contract and isolated rehearsal evidence; this first public release has no earlier public Gridstator installation to update.
