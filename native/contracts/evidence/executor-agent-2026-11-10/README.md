This directory records exact native acceptance for the 29 frozen executor tests and four frozen agent tests listed in `acceptance.json`. Its row mappings are proposals for the parent-owned ledger. The recorded Linux amd64 tool/runtime results do not establish the macOS, ARM64 or stable-signing gates.

The real updater proof uses independently managed standalone worker and controller processes, with two actual compiled host payloads reused from the cutover rehearsal. It pauses only its owned supervisor while the old payload activates the downloaded build, checks the durable prelaunch state, resumes that same launcher and verifies the actual new executable rejoins and confirms. Non-host archive entries are explicitly parser fixtures. See `independent-worker-update.json` and the per-build source SHA manifests in `../linux-cutover-2026-11-10/`.

`executor-tool-initial.log` intentionally preserves the first run: 13 pass and one fixture-only red assertion. The corrected load case is proven in `executor-load.log`; strengthened Actions and setup-output/cancellation cases have their own green logs. No blanket green result is claimed for that initial command.

Reproduce ordinary checks from `native/` with `cargo test --locked --lib executor::`, `cargo test --locked --test executor_contract`, `cargo test --locked --test worker_contract pinned_relocation`, and `cargo test --locked --test updates_contract auto_window_offline_update_only_and_unmanaged_skips_are_distinct`. Run actual executor acceptance explicitly with `cargo test --locked --test executor_contract -- --ignored --test-threads=1 --nocapture`; missing tools fail rather than silently skipping. Run managed updater proof with `GRIDSTATOR_WORKER_UPDATE_FIXTURES=<rehearsal-directory> cargo test --locked --test worker_contract independent_managed_worker -- --ignored --nocapture`.
